# Backend roadmap

- **Sprint 05 — Trusted backend foundation:** versioned NestJS API, Firebase Admin token verification, security middleware, health/readiness, OpenAPI, emulator fixtures, and local orchestration.
- **Sprint 06 — Merchant application/admin APIs and frontend migration:** move merchant application/review data access behind authenticated backend APIs and migrate the relevant frontend flows. This sprint will not add the dashboard UI.
- **Sprint 07 — Admin dashboard:** build the protected review dashboard on top of the Sprint 06 contracts, including the deferred custom live-product UI verification.

This roadmap intentionally leaves current public catalog browsing and the static Next.js export unchanged during Sprint 05.
